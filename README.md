# 🛠️ 리서치 데이터 자동 태깅 & 시각화 대시보드


## 📌 기획 배경 및 문제 의식
1. **정성 데이터 라벨링 리소스 과다**: 인터뷰 전사본 및 설문 텍스트를 엑셀에서 수작업으로 분류·태깅할 때 많은 리드타임이 소요됨
2. **금융권 고객 데이터 보안 원칙 준수**: 실무 데이터를 외부 상용 AI에 그대로 업로드할 수 없는 보안 환경을 고려, **브라우저 단(Client-side)에서 개인정보(이름, 연락처 등)를 자동 마스킹**하도록 설계
3. **리서치-개발 협업 포맷 표준화**: 가공된 데이터를 사내 엑셀(CSV) 및 시스템 적재용 표준 JSON 포맷으로 즉시 추출 가능하도록 지원

---

## 🚀 핵심 기능 (Key Features)

### 1. 개인정보 비식별화 (Privacy Protection)
- CSV 파일 업로드 시 텍스트 내 포함된 전화번호(`010-****-1234`), 이름(`김*준`) 등 개인식별정보(PII) 자동 마스킹 처리

### 2. 정성 데이터 자동 라벨링 & 태깅
- **카테고리 분류**: 송금, 결제, 자산관리, 인증/보안, UI/가독성, 혜택/이벤트, 시스템/성능
- **심각도(Severity) 판정**: 
  - `High`: 심각한 과업 실패 및 금전적 불안 유발 오류
  - `Mid`: 혼선, 머뭇거림, 가독성 불편
  - `Low`: 단순 기능 제안 및 긍정 피드백

### 3. 실시간 인터랙티브 시각화 대시보드
- 카테고리별 발생 빈도 막대그래프 (Bar Chart)
- 사용자 감성 및 심각도 분포 도넛 차트 (Donut Chart)
- 핵심 인용구(Verbatim) 하이라이트

### 4. 양방향 데이터 내보내기 (Export)
- **가공된 CSV 다운로드**: UTF-8 BOM 지원으로 엑셀에서 깨짐 없이 바로 열람 가능
- **표준 JSON 내보내기**: 리서치 관리 툴 및 DB 적재용 구조화 데이터 원클릭 복사

## 💡 회고 (Learnings)
- AI를 활용한 텍스트 구조화와 클라이언트 단 마스킹 로직을 통해 반복적인 1차 태깅 시간을 획기적으로 단축할 수 있음을 검증했습니다.
- AI 도구는 신속한 초안 생성과 시각화를 돕는 든든한 파트너이며, 최종적인 심층 인사이트 도출과 뉘앙스 파악은 리서처의 현장 맥락 검증이 결합될 때 가장 높은 완성도를 낸다는 점을 체감했습니다.
